# Student Performance Analysis
# Project Overview
The Student Performance Analysis project utilizes SQL to investigate the various socio-economic, educational, and demographic factors that influence student academic outcomes. By querying a relational database, this analysis uncovers actionable insights into test scores across different categories.
# Key Queries & Insights
Test Preparation & Education: Examines the impact of test preparation courses and parental levels of education on student performance.
Demographic & Socio-economic Trends: Highlights correlations between student performance and attributes such as gender, lunch types, and race/ethnicity.
Top Performers: Identifies the number of students achieving perfect scores in specific subjects to pinpoint high-achieving groups.
# Tech Stack
Database Management: PostgreSQL, pgAdmin
Language/Tool: SQL (Structured Query Language)
